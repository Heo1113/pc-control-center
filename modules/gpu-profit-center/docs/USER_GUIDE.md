# 사용 방법

## 설치와 실행

1. `GpuProfitCenter-win-x64.zip`을 원하는 폴더에 풉니다. .NET을 따로 설치할 필요가 없습니다(자체 포함 EXE).
2. `GpuProfitCenter.exe`를 실행합니다. 관리자 권한은 필요 없고 요청하지도 않습니다.
3. 압축 안의 `portable.txt` 때문에 데이터는 실행 파일 옆 `data` 폴더에 저장됩니다(포터블 모드). 이 파일을 지우면 `%LOCALAPPDATA%\GpuProfitCenter`를 씁니다.
4. 같은 데이터 폴더로는 한 번에 하나만 실행됩니다(GUI 또는 `gpc`의 쓰기 명령).

NVIDIA GPU와 드라이버가 있으면 NVML로 GPU 값을 읽습니다. GPU가 없거나 지원하지 않는 값은 N/A로 표시하며, 앱은 그대로 동작합니다.
GPU를 직접 측정할 수 없는 PC에서는 외부 전력계 값으로 세션을 계산할 수 있습니다.

명령줄 옵션: `--data-dir 폴더`, `--mock-sensors`(가상 센서), `--demo-data`(MOCK 데모 세션 추가), `--smoke-test`, `--smoke-report 폴더`, `--start-test-session`(복구 시험용).

## 처음 할 일

1. **설정 → 전기요금과 전력 가정**: 유효 단가(원/kWh)를 입력합니다. 고지서 총액 ÷ 사용량처럼 사용자가 정한 단가를 쓰면 그 단가 기준으로 정확합니다.
   PC 전체 전력을 반영하려면 "시스템 추가 전력 가정"(CPU·메인보드·팬·전원 손실 등)을 W로 넣고 기본 전력 산정 기준을 "GPU 실측 + 시스템 추가 전력 가정"으로 고릅니다.
2. **세션 → 작업**: 작업을 만듭니다(예: "GPU 채굴 A", "LLM 추론 서비스"). 유형은 채굴·AI 추론·GPU 컴퓨팅·기타 중에서 고릅니다.
3. 작업 프로그램(채굴기, 추론 서버 등)은 이 앱 밖에서 직접 실행합니다. 이 앱은 작업을 실행·설치·변경하지 않습니다.

## 세션 기록

- **기록 시작**: 대시보드나 세션 화면에서 작업을 고르고 시작합니다. 여러 GPU 중 일부만 쓰는 작업이면 GPU 번호(예: `0` 또는 `0,1`)를 입력합니다.
- **일시정지 / 재개**: 일시정지 시간은 세션 시간과 에너지에 들어가지 않습니다.
- **종료**: 계산 결과를 조건과 함께 저장합니다. **중단**은 작업이 실패·취소된 경우이며, 기록은 지우지 않고 중단으로 표시합니다.
- **작업 실행 확인**: 기록 버튼은 측정 구간을 표시할 뿐입니다. 작업이 실제로 돌았는지 확인했다면 세션 설정에서 체크하세요. 체크하지 않으면 GPU 사용률만 참고로 보여 줍니다.
- **앱을 닫으면** 기록 중인 세션은 일시정지됩니다. **앱이 강제 종료되거나 PC가 꺼지면** 다음 실행 때 마지막 기록 시점에서 세션을 닫고 알려 줍니다. 앱이 꺼져 있던 시간은 세션에 넣지 않으며, 세션 화면에서 재개할 수 있습니다.
- **절전**: 절전 구간은 공백으로 기록되고 에너지에 넣지 않습니다.
- **지난 세션 직접 입력**: 시작·종료 시각과 (있으면) 외부 전력계 kWh를 입력합니다. 그 시간에 기록된 센서 값이 있으면 함께 씁니다.

세션 상세의 탭에서 요약, 에너지 구성(출처별), GPU별 에너지(관측률·평균·중앙값·P95·NVML 카운터 비교), 구간과 공백, 전력 그래프, 세션 설정을 볼 수 있습니다.
세션 설정에서 전력 산정 기준, 미관측 구간 처리, 가정 W, 외부 전력계 kWh, 세션 전용 단가, 사용자 입력 작업 시간을 세션마다 바꿀 수 있습니다.

## 수익과 비용 (수익성 화면)

- **수익 종류**를 정확히 고르세요: 실제 수령 / 미정산·미수령 / 외부 서비스 보고 / 예상(가정). 확정 손익은 실제 수령만 씁니다.
  미수령 금액이 들어오면 "선택 항목 수령 확인"으로 바꿉니다.
- 외화·코인 수익은 통화 코드(USD, BTC 등)로 입력하고, 항목에 원화 환율을 넣거나 설정 화면에 환율을 등록합니다. 환율이 없으면 원화 합계를 "계산 불가"로 표시합니다.
- "수수료 전 금액"을 체크한 수익에만 비율 수수료가 붙습니다.
- **비용**: 이 세션만 / 이 작업의 모든 세션 / 모든 세션에 걸 수 있습니다. 월 금액은 세션 시간 비율로 배분됩니다(추정).
- **지급 내역 CSV 가져오기**: 풀·서비스에서 내려받은 CSV(첫 줄은 열 이름, `time`/`date`와 `amount` 열 필요)를 가져옵니다. 같은 파일을 다시 가져와도 중복되지 않습니다.
- 손익 요약에는 매출, 전력비, 기타 비용, 수수료, 총비용, 순수익, 시간당·kWh당 순수익, 수익률, 손익분기 매출, 손익분기 전력 단가, 장비 회수 기간이 나옵니다. 계산할 수 없는 값은 이유와 함께 N/A로 표시합니다.
- **계산 저장**: 지금 조건의 계산을 이력에 남깁니다. 마지막 저장 이후 입력이나 조건이 바뀌면 화면 위쪽에 알려 줍니다.

장비(감가상각)와 환율은 설정 화면에서 관리합니다.

## 비교

기간을 고르고 세션을 체크한 뒤 "비교 실행"을 누릅니다. 세션별(시간당·kWh당 정규화), 작업 유형별, 작업별, 시간대별, 실제 대비 예상 수익을 보여 줍니다.
전력 산정 기준·전기요금 단가·MOCK 여부·관측률·시간 기준·작업 유형이 서로 다르면 경고합니다.

## 시나리오

시나리오는 **조건부 계산**이며 미래 가격·수익·전기요금을 예측하지 않습니다.

- "세션에서 가져오기": 기록된 세션의 실측 평균 GPU 전력, 시간당 수익, 단가로 조건을 채웁니다.
- 수익 단가, GPU 소비전력, 시스템 추가 전력, 전기요금, 가동률, 하루 작업 시간, 기간, 수수료, 월 고정비, 장비 비용을 바꿔 계산합니다.
- "낙관·비관 만들기": 수익 ±20%, 전력·요금 ∓20%인 시나리오를 추가합니다.
- 민감도 그래프는 한 조건만 바꿨을 때의 순수익과 손익분기점(노란 표시), 현재 조건(회색 표시), 손익 0선(빨간 선)을 보여 줍니다.
- 조건별 영향 표는 각 조건을 ±N% 바꿨을 때 순수익 변화가 큰 순서로 보여 줍니다.

## 기록

일·주·월별 에너지(실측·추정·전력계 입력), 비용, 실현 매출, 미확정·예상 수익, 실현 순수익, 추정 비중, 관측률을 보여 주고 CSV로 내보냅니다.
아래에는 최근 24시간·7일·30일의 GPU 전력·사용률·온도 시계열과 기록 공백이 있습니다.

## 백업과 복원

- **설정 → 백업**: 일관된 사본을 만들고 검증합니다.
- **백업에서 복원**: 파일을 검증한 뒤 현재 데이터베이스를 옆에 보관하고 바꾼 다음 앱을 다시 시작합니다.
- **무결성 검사**: SQLite `integrity_check`를 실행합니다.
- **전체 JSON 내보내기 / CSV 내보내기**: 메모 등 직접 입력한 내용이 들어 있으니 공유 전에 확인하세요.

## 명령줄 (`gpc.exe`)

```
gpc status [--json]                 데이터베이스·무결성·열린 실행과 세션 (읽기 전용)
gpc sessions [--json] [--limit N]   세션별 계산 결과
gpc recalc [--session ID]           재계산 후 바뀐 결과 저장
gpc export --out 파일 [--format csv|json] [--view realized|unconfirmed|expected]
gpc periods --out 파일 [--by day|week|month]
gpc backup --out 파일               백업 (덮어쓰지 않음)
gpc verify-backup 파일
gpc demo-data                       MOCK 데모 세션 추가
```
모든 명령에 `--data-dir 폴더`를 쓸 수 있습니다.

## 하지 않는 일

채굴·작업 실행, 채굴 소프트웨어 설치, 풀 변경, 지갑 개인키 보관, 암호화폐 거래, 오버클럭·언더볼팅·전력 제한 변경, BIOS·전압 설정, 드라이버 설치·삭제, 외부 API 호출을 하지 않습니다.
